    Settings & Setup

    1. First-time connection

    1. Power on AgriRobo. The ESP32 creates or joins a Wi-Fi network.
    2. Connect your phone to the same Wi-Fi network as the robot (or join the robot's hotspot, e.g. AgriRobo-AP).
    3. Find the robot's address (shown on the robot's serial monitor, e.g. 192.168.4.1).
    4. Enter the address below and tap Test & Save.

    Local Wi-Fi only reaches the robot on that network. For remote access from anywhere, the ESP32 must send data to a cloud IoT backend (see README).

    Soil Moisture Calibration

    Raw ADC values differ per sensor and soil. Calibrate by lifting the sensor out of dry soil (note raw = "dry") and into wet soil (note raw = "wet"). The app converts live raw readings to a percentage.

    Troubleshooting

    • Stuck on "Disconnected" — confirm the phone and ESP32 are on the same Wi-Fi network (not mobile data).
    • CORS / network error — the ESP32 firmware must send CORS headers (the provided firmware does). Try the IP directly, not a wrong hostname.
    • Wrong readings — recalibrate the soil sensor in Settings; ensure the DHT11 data pin matches the firmware.
    • Need remote access — local Wi-Fi cannot be reached from outside the network. Use a cloud IoT backend or a VPN/tunnel.
